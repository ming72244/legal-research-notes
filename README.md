# 公开法律研究笔记

这里交接可以公开发布的研究稿和复核意见。资料以官方链接、案号和自写摘要为主。个案卷宗、脱敏案件分析、身份对应表、数据库订阅正文和访问密钥均留在各自获准的环境。

## 交接方法

1. 研究者为公开问题选一个小写英文编号，研究稿保存为 `research/编号.md`。同一编号对应一版固定稿，修订时另取编号。
2. 复核者打开对应文件，核对请求方、裁判理由、原文出处、适用时间及未解决的问题。把意见保存为 `reviews/编号.md`，首行写 `research_blob: 研究稿的 Git blob SHA`。可以从发布回执或 GitHub Contents API 得到该值。
3. 本地法律助手读取复核意见，确认引用的是同一版本，由使用者决定写入哪一页本地争点笔记。
